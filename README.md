# High Protein Meal Plan Website

# Overview
This project is a basic HTML-based website that outlines a daily meal plan designed to support muscle growth by ensuring adequate protein intake. The website provides meal ideas for Breakfast, Lunch, and Dinner.

# Features
Breakfast, Lunch, and Dinner Pages: Each meal has a dedicated page with detailed meal ideas for high-protein options.
Simple Navigation: Links are provided for easy access to the breakfast, lunch, and dinner meal ideas.
# Files Included
index.html: The homepage that introduces the high-protein meal plan and includes links to breakfast, lunch, and dinner pages.
meals/breakfast.html: Contains the meal plan for breakfast.
meals/lunch.html: Contains the meal plan for lunch.
meals/dinner.html: Contains the meal plan for dinner.
# HTML Structure
Head Section:
The <meta charset="UTF-8"> tag ensures proper character encoding for the page.
The <title> tag defines the title of the webpage, which is displayed in the browser tab.

Body Section:
The main heading <h1> introduces the purpose of the page.
An unordered list (<ul>) contains links to the individual meal plan pages, such as breakfast, lunch, and dinner.

# How to Use
Clone or download the repository.
Open index.html in a browser to view the High Protein Meal Plan webpage.
Navigate to breakfast, lunch, and dinner pages by clicking on the links in the list.
